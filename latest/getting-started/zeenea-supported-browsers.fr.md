# Navigateurs pris en charge

!!! warning "Traduction automatique"

Les applications Zeenea Studio et Explorer peuvent s'exécuter sur n'importe quel ordinateur disposant d'une connexion Internet et prennent en charge les navigateurs suivants :

| Navigateur | Remarques |
| :--- | :--- |
| Google Chrome™<br />Version stable la plus récente | Zeenea met tout en œuvre pour tester et prendre en charge la version la plus récente de Chrome. Aucune recommandation de configuration n'est nécessaire pour Chrome. |
| Mozilla® Firefox®<br />Version stable la plus récente | Zeenea met tout en œuvre pour tester et prendre en charge la version la plus récente de Firefox. Aucune recommandation de configuration n'est nécessaire pour Firefox. |
| Microsoft® Edge® | Si vous utilisez Edge, nous vous recommandons d'utiliser la dernière version prise en charge par Zeenea. Appliquez toutes les mises à jour logicielles Microsoft. |
| Apple® Safari®<br />Versions 11.x et 12.x sur Mac OS X | Aucune recommandation de configuration n'est nécessaire pour Safari. |

Recommandations pour tous les navigateurs :

* Pour tous les navigateurs, vous devez activer JavaScript, les cookies et au minimum TLS 1.0.
* Nous recommandons une résolution d'écran minimale de 1440x900 pour une expérience utilisateur optimale.
