# Item Attachments 

Attach files to catalog items through the public API, then find, download, and manage them using the API, Studio and Explorer.

An *item attachment* is a file that you upload through the public API and attach to a catalog item. Use attachments to keep supporting materials, such as specifications, diagrams, and configuration files, with the items they describe.

On Data Products, Output Ports and Data Contracts, attachment lists can also include files generated by the platform. These files are read-only and cannot be uploaded, replaced, or deleted through the Item Attachments API.

The following table summarizes the available attachment capabilities:

| Capability | Where | Availability |
| --- | --- | --- |
| Upload files to catalog items (PDF, PNG, JPEG, JSON, YAML, TXT, MD) |API | Available |
| Upload a consumption locations descriptor to a Use Case | API | Beta |
| List item attachments | API | Available |
| Download attachments | API, Studio, and Explorer | Available |
| Delete attachments | API | Available |
| View attachments | Studio and Explorer | Available (Beta for consumption locations descriptors) |
| Upload, edit, or delete attachments from Studio or Explorer | Studio and Explorer | Not available |

Attachments can be uploaded and deleted only through the API. For more information, see the [Item Attachments API](../../technical-documentation/api/item-attachments-api.md).

Studio and Explorer support viewing and downloading attachments.

## View Attachments

Attachments are displayed on catalog items in both Studio and Explorer.

In both applications, the **Attachments** section:

- Displays the number of attachments.
- Lists available attachments.
- Allows you to download attachments.
- Shows the first five attachments by default.
- Provides Show All and Show Less options when additional attachments are available.

The **Attachments** section is hidden when an item has no attachments.

### In Studio

On the Item Details page, attachments appear in the **Attachments** section of the **Properties** tab in the right-side panel, under the **General** tab.

### In Explorer

On the item details page, attachments appear in the **Attachments** section of the **Details** tab in the left-side panel.

## Download Attachments

To download an attachment:

1. Open the item.
2. Locate the **Attachments** section.
3. Select the attachment name.

The file is downloaded using its original file name.

Attachments are downloaded directly and cannot be previewed in the application.

### Download Error Messages

The following error messages can be displayed when downloading an attachment:

- **Couldn't download `<file name>`.**
     
    Displayed when the download request fails. Select **Retry** to try the download again.

- **`<file name>` is no longer available.**

    Displayed when the attachment was deleted after the page loaded. The attachment is removed from the list.

- **`<file name>` can't be downloaded because it didn't pass the security scan.**

    Displayed when the file does not pass the security scan. The attachment remains visible in the list but cannot be downloaded.

## Activity History

Attachment activities are recorded in the item's activity history.

The activity history records:

- Attachment uploads
- Attachment replacements
- Attachment deletions

For example:

*"\<API key name> added the attachment report.pdf"*. 

The API key name is recorded, never its secret.

Attachment downloads are not recorded.

## Consumption Locations Descriptors (Beta)

A Consumption Locations Descriptor is a special attachment that can be associated with a Use Case.

When configured, the descriptor provides predefined destination information for access request workflows.

In Explorer, when a requester selects a Use Case with a Consumption Locations Descriptor, the access request form allows the requester to select a destination defined by the descriptor.

In attachment lists, Consumption Locations Descriptors are displayed separately from other attachments. The descriptor appears first in the list and is displayed as *Consumption locations descriptor: file name*. Other attachments are displayed using only the file name.

## Limitations

- Attachments can be uploaded and deleted only through the API.
- Studio and Explorer do not support uploading, editing, or deleting attachments.
- Attachments cannot be previewed within the application.
- Attachment content cannot be searched.
- Each item can have up to 20 attachments.
- Individual files cannot exceed 10,000,000 bytes.
- A Use Case can have only one consumption locations descriptor. Version history is not available.
