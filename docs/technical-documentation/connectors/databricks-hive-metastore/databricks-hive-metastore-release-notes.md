# Databricks Hive Metastore Release Notes

The latest version of the **Databricks** connector plugin is available for download from the [Connector Downloads](../connectors-list.md) page.

## November 10, 2026 — Version 2.3.1

**Enhancements**

The **Catalog Name**, **Schema Name**, and **Type** properties are replaced by the common **Catalog**, **Schema**, and **Type** properties. The previous properties should be deleted manually.

## October 30, 2026 — Version 2.3.0

**Enhancements**

Upgraded third-party dependencies to address security vulnerabilities.
