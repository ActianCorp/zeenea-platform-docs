# Scanner Release Notes 

!!! tip "Subscribe to release notes (RSS)"
    Get notified automatically whenever a new connector or scanner version ships —
    no account or sign-up required.

    **How to subscribe:** open the <a href="../../feed_rss_updated.xml">release notes feed</a>,
    copy its URL from your browser's address bar, and add it to any RSS reader —
    for example **Feedly**, **Inoreader**, **NetNewsWire**, or **Thunderbird**. For
    team alerts, use **Slack** (`/feed subscribe <feed URL>`) or add the **RSS**
    connector to a **Microsoft Teams** channel. Your reader then checks the feed
    periodically and flags each new release for you.

    Opening the feed URL directly in a browser shows raw XML — that's expected,
    because browsers have no built-in feed reader. Paste it into one of the readers
    above to see it as a formatted article.

The latest scanner version is available for download from the platform administration.
